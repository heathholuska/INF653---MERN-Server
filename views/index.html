US States Data REST API

Welcome to the US States Data API. This service provides information about US states, including nicknames, populations, and fun facts.

API Endpoints

  • GET /states/ - Get all state data [cite: 66]
  • GET /states/:state - Get data for a specific state code [cite: 66]
  • GET /states/:state/funfact - Get a random fun fact [cite: 66]
